# V2 executor

This implements the controlling protocol locally. Synthetic inputs live only in pytest fixtures. No real Stage1 slot has been claimed and no Stage2 outcome bundle has been opened during implementation.

Run tests with `.venv/bin/python -m pytest -q`. Execute verified Stage1 with `.venv/bin/python -m sector_pipeline execute --stage 1 --bundle <local-stage1.json>`. The Stage2 command has the same syntax with `--stage 2`; it checks the committed Stage1 result, complete twelve-test family, gate decisions and configuration/claim bindings **before resolving or opening its input**. Only passing signal/horizon pairs are evaluated, plus their exploratory six-month decay. Legacy `run` remains sealed. There is no force-release option. Do not run legacy pilot scripts as v2.

The once-only slot is `research_state/stage1-claim.json`, independent of input/configuration hashes. Atomic hard-link publication prevents overwrite; fsync covers files and directories. An exclusive process lock prevents duplicate evaluations. The configuration freezes manifest, controlling protocol, conventions and implementation bytes. Identical input/configuration can resume deterministically after a crash; a completed run returns its original result. Changed inputs or code cannot reuse the claimed slot. A local filesystem owner can delete files; this is an operational ledger, not a tamper-proof remote service. Preserve `research_state` across restarts.

Source acquisition can use `adapters.checkpoint_source(provider, request, cache)` for explicit SEC, Alpha Vantage, Yahoo or FRED requests. It stores immutable provider/request objects and payload hashes, skips completed objects and retries failures without a successful checkpoint. There is no automatic vendor fallback or network acquisition in the executor CLI. Yahoo remains provisional and fails certified coverage.

A stage-specific JSON bundle contains:

- `stage`: 1 or 2. Stage1 contains formation inputs for 2006–2015, with necessary prehistory and terminal prices through June 2016; do not include a blind Stage2 formation bundle.
- `sessions`: strictly increasing explicit exchange session dates; `opens` and `closes`: date to timezone-aware execution-open and formation-close timestamps. These must come from reviewed calendar evidence, not price-panel inference.
- `members`: PIT intervals with `symbol`, permanent `identity`, `sector`, inclusive `start`, exclusive `end`, and `available_at`. `inventory` maps each formation session to the independently reconstructed complete constituent list, including exits.
- `prices`: symbol to sorted daily rows with positive finite `adj_open`, `adj_close`, `date`, `open_available_at`, and close `available_at`. Normalization must preserve PIT adjustment provenance in the reviewed archive. Opens must be available at the exchange open, closes at exchange close. No proxy or terminal substitution is allowed.
- `fundamentals`: symbol to SEC companyfacts shape; `earnings`: symbol to Alpha Vantage earnings shape. Every supplied source record requires timezone-aware `available_at`. Actual availability is checked when selecting records; SEC filing date plus one calendar day and conservative exclusion of same-day earnings also apply. Annual GP and same-period assets are required, as are eight prior surprises.
- `evidence`: entries for `calendar`, `membership`, `gics`, `identities`, `prices`, `fundamentals`, `earnings`. Each requires `status: verified`, `reviewer`, `method`, `provider`, local `path`, and `sha256`. Each evidence JSON archive must contain `normalized_hash`, binding its reviewed normalized contents with `storage.digest`. Calendar binds `{sessions,closes,opens}`; membership binds `{members,inventory}`; GICS and identities each bind `members`; the remaining kinds bind their same-named bundle field. Evidence bytes and normalized hashes are verified. This checks integrity and coverage, not independent truth of a review attestation. Wikipedia alone cannot satisfy PIT history/GICS.

Every expected month, member, required historical/terminal quote and source timestamp is checked. Missingness reports retain missing securities, entire missing formations, missing signals and incomplete sector benchmarks. A coverage failure does not consume a Stage1 evaluation slot. Once evaluation starts, its immutable claim remains even after failure. Valid Stage1 requires all twelve primary tests to have complete monthly sector coverage. A non-passing but valid run is logged and releases nothing.

Results include sector/month Spearman IC, equal-sector monthly HAC inference, twelve-test Holm adjustment including H6 (missing p-values do not shrink the family), direction-aware gate/placebo decisions, four chronological blocks, 1/3/6 decay, portfolio turnover, costs and missingness. The 1000 shuffles independently permute returns inside each sector-month; undefined IC is reported as undefined rather than fabricated. Six months is exploratory. Future-month signal versus prior return is a warning diagnostic, not proof of leakage.

Each decile leg has unit gross weight. Before a monthly rebalance, previous holdings drift using actual next-open to following-rebalance-open returns, separately normalized within each leg. Cost is `.0015 * sum(abs(new_weight - drifted_weight))` across both legs. Initial entry costs .003; missing marks or gaps make turnover and net spreads unavailable. Monthly costs are diagnostics at each reported horizon; overlapping 3/6-month returns are not an independently simulated sleeve portfolio. Decile ties stay intact.

Stage2 reports the full period as contaminated-year-inclusive context and **uses the separate 2019/2020-excluded evaluation for final decisions**. Calendar HAC does not bridge removed years. Holdings are marked on the full calendar before excluding performance months, so January 2021 turnover remains measurable without pretending 2018 and 2021 are consecutive trading months. Only predeclared exclusions tolerate gaps in inference. Later variants must be registered immutably with the expanded test family; variant execution is deliberately not exposed.

H1 indexing is resolved: month t is the formation month; inclusive monthly returns t−12 through t−2 are eleven returns, so H1 = close(t−2)/close(t−13) − 1. Missing endpoints stay missing.
