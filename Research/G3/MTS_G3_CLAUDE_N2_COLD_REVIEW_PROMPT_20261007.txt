You are serving as an independent outside scientist/statistical-methodology reviewer. Review the following experimental-design problem cold. Do not assume any proposed repair; recommend from first principles.

PROJECT
G3 is a financial-market research system intended to discover local opportunity specialists first, validate them, and only later construct portfolios. Discovery is explicitly NOT optimized on portfolio CAGR or maximum drawdown. Candidate specialists have causal feature gates/signals and lifecycle management; evaluation returns include net return, MFE, MAE, tail loss, duration, time-to-profit/failure, turnover/costs, and path signatures. A genetic/evolutionary search is used. Before any large discovery run, the machinery must demonstrate that real data are distinguishable from matched null controls under equal search budgets.

PILOT DATA
8 stocks: AAPL, MSFT, XOM, JPM, JNJ, CAT, WMT, NVDA.
Common aligned date panel: 4,935 dates from 2007-01-19 through 2026-08-31. Pilot uses last 2,500 common dates. Features are causal/past-only price features plus point-in-time earnings features. Outcomes are complete 10-session forward paths. Search: 6 generations, population 48, equal 2,304 ticker evaluations per arm, same search machinery and seed structure.

NULLS
N1 TEMPORAL BLOCK: within each stock, permute outcome paths in temporal blocks, breaking local feature→future association while approximately retaining temporal structure.
N2 DATEWISE CROSS SECTION: on each actual date, permute the complete forward outcome paths among the 8 stocks. Thus the exact cross-sectional multiset of outcomes for every date is preserved, and pooled outcome distribution is preserved exactly, but stock identity linking each feature vector to its own future path is broken.
N3 GUARDED SHIFT: within each stock, circularly shift outcomes by a guarded offset to break contemporaneous feature→future association while preserving each stock's marginal outcome series structure.
