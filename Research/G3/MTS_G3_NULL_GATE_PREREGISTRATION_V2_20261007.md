## Prospective V2 search repair
The specialist genome, lifecycle evaluator, objectives, costs, null families, panel, inferential endpoint, replication count, and statistical gate remain unchanged from V1.

The sole search-design repair is initialization:
1. Before lifecycle evolution, deterministically screen the existing two-rule structural vocabulary.
2. Candidate rule thresholds are frozen at standardized values {-1.0, 0.0, +1.0}; both directions, all ordered feature pairs, and both long/short sides are screened.
3. Structural candidates are ranked by mean signed 10-session compounded return over their firing events, requiring at least 25 pooled events.
4. The top population structures seed the existing evolutionary lifecycle search with neutral lifecycle values: TP .08, SL .06, horizon 10, add .04, reduce .04.
5. The existing 6-generation, population-48 evolutionary machinery then proceeds unchanged.
6. The structural screen is adaptive search work. It runs identically and independently inside every Real and null arm; it is never computed on Real and transferred to a null, or vice versa.

This repair was selected without consulting any V2 real-vs-null outcome. On deliberately planted synthetic conjunctions, the old 6x48 search substantially missed the known oracle in 10/10 diagnostic runs. The repaired search recovered approximately oracle-level performance in 5/5 independent planted runs. A crossover-only repair was also tested on planted data and rejected because it did not solve reachability.

## Frozen inference
- 25 independent paired replicates; identical search seed across Real/N-A/N-B/N-C within replicate.
- Primary endpoint: final-generation median candidate mean net return.
- One-sided paired Wilcoxon Real > Null separately for each null.
- Bonferroni alpha 0.0166666667 per null.
- PASS requires >=2/3 significant null comparisons; 3/3 strong pass; <=1/3 fail.
- Generation counts are descriptive only.
- No interim stopping or tuning.
