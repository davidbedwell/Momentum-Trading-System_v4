Date: 2026-10-07
Status: PROSPECTIVELY FROZEN BEFORE CURRENT V3 RESULT EXISTS

Purpose: implement the already-frozen V3 requirement for chronological temporal validation that the first executable omitted.

Unchanged: 8-stock panel, 2500 aligned rows, exact three-rule local structural screen, population 48, six lifecycle generations, Real + N-A/N-B/N-C, 25 paired replicates, one-sided paired Wilcoxon, Bonferroni alpha 0.05/3, pass >=2/3 nulls, no ticker identity, identical Real/null adaptive work.

Temporal execution: each transformed arm is split before discovery. First 70% is adaptive discovery. A 10-session embargo follows. Remaining rows are untouched temporal validation. Structural screening and all six evolutionary generations see discovery only. After generation six, the candidate population is frozen. The validation endpoint is the median mean net return among frozen candidates with >=25 validation events, aggregated across the same eight stocks. Validation performs no mutation, crossover, ranking repair, threshold tuning, or scope change.

Null transformation occurs before the chronological split, so each Real/null arm runs the complete same discovery->freeze->temporal-validation pipeline.

The first nonconforming V3 result, if completed, is diagnostic only and cannot authorize large discovery. A conforming PASS under this amendment is required.
