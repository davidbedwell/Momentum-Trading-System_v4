# Accountability Engine

This directory contains the implementation of the canonical MTS Accountability
Engine.

Its governed responsibilities are defined by:

- `Architecture/ACCOUNTABILITY_ARCHITECTURE.md`
- `Architecture/ENGINE_ARCHITECTURE.md`
- applicable Governance Standards, Policies, Contracts, and Schemas.

The engine controls the Research Admission and Knowledge Promotion gates.

This directory is organizational only. Component identity, routing, authority,
dependency, and workflow do not derive from this path.
