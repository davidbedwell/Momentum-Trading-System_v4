# GA10 frozen experimental design

Scope: isolated prototype, no production integration and no GA6/GA7 imports. Frozen monthly opportunity pool: rank finite Wilder/EWM RSI14 ascending, alphabetical ties, floor(N/5), minimum one; intersect with close/SMA20−1 < 0 and consecutive 21-session return acceleration > 0. Snapshot at last close before each calendar month; remains an opportunity pool throughout that month. Screening never places an order. Existing holdings remain eligible for management after leaving the pool; new entries require current pool membership.

Objective: maximize net portfolio CAGR, preferring daily observed maximum drawdown strictly below 25%. Training fitness is lexicographic: feasible first, then CAGR; infeasible candidates prefer smaller MDD. No claimed hard ex ante guarantee of MDD. Costs: 10 bp each bought/sold notional, self-financing, fractional long-only shares, no leverage, immediate proceeds, zero cash yield. Signals from t−1 close, fills t open, marks t close. Portfolio stop also uses prior close. No terminal liquidation, endpoint close valuation.

Genes: four separate linear score heads for conditional entry/add/reduce/exit; per-name allocation score head; learned entry fraction, add fraction, reduction fraction, maximum stock weight, portfolio exposure and prior-close drawdown stop. Predictors: RSI, MA20 distance, acceleration21, return5, return63, volatility21, current unrealized return, holding age. Price predictors are lagged; state predictors use prior marks. Exit > reduce > add > hold priority. New entry is independent from allocation. Held shares are never sold merely because screening membership changes. Allocation constrained across portfolio after conditional action targets.

Frozen schedule: deterministic seed 10; smoke search population 6, generations 2, train 2009–2010, diagnostic evaluation 2011. Scale gate depends ONLY on functionality tests, finite accounting, actual GA trades, and reproducible training winner; never smoke returns. If passed, bounded search population 12, generations 3, training 2009–2013; freeze winner then evaluate 2014–2018 exactly once. This is previously examined holdout, not untouched validation: screen was selected in earlier studies and the universe is retrospective. No 2019+ evaluation. Reset capital/positions at every split. No labels or outcome windows in predictors. No validation-based model/seed/rule selection. All attempted fitnesses exported. Stop after this bounded search and report regardless of returns; no wider search. Hard run timeout 180 seconds.

Evaluation: same execution/accounting for GA10, frozen monthly equal-weight RSI+setup purchaser baseline, and frozen monthly equal-weight RSI-only purchaser baseline. Export daily NAV, actual trades/actions, monthly screens, candidate fitness, frozen genome, metrics (net CAGR, daily MDD including open/close marks and initial capital, annualized volatility, Sharpe, turnover, costs, exposure, actions) and paired CAGR differences. Unit checks precede smoke: temporal prefix invariance, screen nonpurchase, offscreen holding management, all action branches, fee/cash reconciliation and absent-price failure. No certification or external data work.

Data: local DEV79 parquet, adjusted close and open×adj_close/close. Historical adjusted prices and fixed survivor universe are not certified PIT. No fundamentals or restated nonprice fields used. Missing features block entries; held missing execution/mark prices raise rather than fabricate returns. The simulation is causally timed conditional on the supplied archive, not a claim of PIT data provenance.
