# MTS GA review and state-aware decision function — approved design (2026-10-27)

1. Evolve a rich, state-aware decision function OFFLINE. Its runtime decision function continuously evaluates current observable market state (conditional remaining-path EV, MAE/MFE, current R, duration-dependent edge, volatility, regime, opportunity cost, correlation, and risk-constrained scaling). Changing state changes the recommendation without requiring re-evolution.
2. Every FRIDAY NIGHT after market close, conduct an evolutionary review for changing conditions. Evaluate incumbent chromosomes and candidate challengers on recently matured chronological evidence; only run additional evolutionary search where justified by drift, deterioration, undercoverage or novel market states. This is a scheduled review, not mandatory wholesale replacement.
3. Trigger an extraordinary review after a dramatic CAUSALLY DETECTED regime change, using thresholds derived without future data. Crash-defense A/B/B1/C and R-1 act under their own immediate runtime policies and NEVER wait for GA retraining.
4. CHAMPION–CHALLENGER GOVERNANCE (explicitly approved): Keep the currently approved champion deployed while candidate challengers are evaluated in shadow. Separate challenger generation/evaluation from promotion. Require independent out-of-sample chronological evidence of improved net PORTFOLIO performance, calibration, and downside/tail-risk control before promotion; recent fitness alone is insufficient. Maintain immutable model versions, reproducible data cutoffs, promotion logs, and rollback capability. Avoid tuning on sealed holdouts.
5. Do NOT run daily evolutionary re-optimization by default. Add it only after measured evidence shows state-aware offline rules lag regime shifts, with explicit compute budget, multiple-testing/overfit controls, and independent proof of net benefit over weekly/event-driven review.
6. Distinguish continuous/daily market decision evaluation from GA evolution. The manager remains responsible for HOLD/ENTER/INCREASE/REDUCE/EXIT/CASH competition, shared capital, risk, settlement and crash-defense compliance. Chromosomes recommend; manager decides. NO universal manager-imposed 40-session holding limit.

Implementation status: governing policy only. No weekly schedule, event detector, challenger promotion system or evolutionary run is created by this document.
