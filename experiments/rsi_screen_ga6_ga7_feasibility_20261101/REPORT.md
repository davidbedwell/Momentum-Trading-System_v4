# Frozen RSI screen × existing GA6/GA7 feasibility

Executed 2009-01-02 through 2018-12-31 (2,516 sessions). **GA7 is executable in a bounded research harness; the requested faithful PIT-routed GA6+GA7 combined replay remains blocked.** No chromosomes were trained, mutated or ranked by these replay results. No production files were changed. Reproduce from repository root with `bash experiments/rsi_screen_ga6_ga7_feasibility_20261101/run.sh` (uses `/opt/mts/.venv/bin/python`).

## Executable library and API audit

- GA6: read-only `ga6/runs/frozen_four_run_20261024/catalogue.sqlite` contains **261,958** structural chromosomes across 13 `NICHE-0001`…`NICHE-0013` groups. `StructuralCandidate.restore` validates identity, genome and entry tree. `ga6/native_position_decision_adapter.py:native_action(candidate,row,held,session_index)` calls the existing GA5/GA6 fast kernel, requires every genome/tree feature, and requires entry-tree qualification. Native exits exist: initial stop, trailing stop, explicitly enabled age exit, exit/hold feature thresholds and replacement. It maps replacement to EXIT, scale-out to retained-fraction REDUCE, and scale-in to incremental ADD. No universal age exit was added. Stops range 0.1%–75%; only 885 catalogue rows have stops ≤2%, so the existing manager's ≤2% stop contract would exclude most of this library without changing genes.
- **GA6 routing block:** these are original retrospective `NICHE-*` genes. The available expanding historical classifier produces different `PIT-NICHE-*` centers; its manifest explicitly warns they are not the original GA6 niches. There is no demonstrated identity-preserving PIT mapping here. Native structural replay accepts omitted niche labels, which bypasses that constraint; this harness does not use that bypass or silently rename the niches. GA6 performance and combined GA6/GA7 performance are **unavailable**, rather than zero.
- GA7: `ga7_audit_v2/validation/handoff/frozen_cohort.json` supplies existing genomes grouped by NON_NICHE and 13 chronological niches. This cohort declares `archive_complete=false`; it is recoverable evidence, not a complete historical library. The harness freezes **the lexicographically smallest identity in each group**, 14 genomes, without reading their discovery metrics for selection. Exact records are in `bank.json`.
- GA7 held API: existing experiment working-copy `ga7_native_daily_producer.decision(genome,bar,position,defensive=...)`. Entry is the actual AND/OR chromosome threshold signal. Held EXIT is defense, retained initial stop, or the chromosome's signal-decay/reversal/volatility rule. ADD requires strength >0.75 and profit >3%; REDUCE requires loss below −1% or strength <0.45; otherwise HOLD. No fabricated missing exit or monthly-screen exit. Current controlling-niche genome manages incumbents, matching `ga7/request_replay.py` bank selection; initial filled stop persists across niche changes. No forced terminal sale was introduced.
- Controlling niche: native `controlling_niche` uses normalized distance ≤1 and a 0.05 switching margin. Distances and annual model metadata come from `ga7_unbounded/niche_pit_manifest.json`; every model's training cutoff must precede its evaluation interval. Missing warmup distances map to NON_NICHE, as in the native loader. Group support is exported in `audit.json`.
- Manager audit: `functional_niche_manager.run_slice` accepts dated `NicheObservation`, explicit eligibility, native proposals, candidate identities and optional priced conditional EV; it rejects GA4 and unpriced selectors, requires stop ≤2%, and requires a prior-trained niche observation. `manager_strategy_registry` still marks its generic GA7 bridge unavailable. Authentic proposal wrappers require training lineage which is not established for 2009. Accordingly this experiment uses the callable **raw native GA7 decision seam plus a minimal deterministic allocation adapter**, not that full manager or an authenticated deployment path. GA4 feature columns are inputs, not a deployable GA4 strategy.

## Frozen screen, eligibility and execution

The existing k2_2-4 list is unchanged: prior-session lowest-20%-RSI candidates AND MA20 distance <0 AND 21-session acceleration >0. The harness independently checks conjunction membership against saved feature rows and verifies feature dates precede execution dates. There are **321 stock-month candidates, 92 nonempty months, 120 monthly screens**. Empty months are cash for the fixed control. For GA7, screen removal blocks new entries/adds but never liquidates incumbents; native daily management continues outside the screen.

Data are the DEV79 raw archive and its existing GA4-feature enrichment, restricted before 2019 during reads. Only **77 of the retrospective 79 symbols have observations in this interval**. Daily membership, blocked dates and risk-veto policy are read explicitly; missing membership fails. Ranks follow native `rank_filtered_sessions` semantics over the eligible observed universe **before** RSI screening, including its existing retention of raw feature units on ineligible rows. That unit discontinuity is inherited and limits interpretation of held decisions; it was not silently repaired. Niche feature provenance is explicitly pending in the source manifest. Historical security membership and publication timestamps are **not independently PIT-certified**; these are causal daily policy gates inside a survivor universe. Chromosome selection/training also postdates the replay. This is retrospective executable feasibility, not a historically available strategy or out-of-sample result.

GA7 allocation uses native entry weights, requested ADD increments, half-position reductions, a 10% name cap, 90% gross cap and 10 slots. Exits/reductions execute first; equal-priority requests use ticker order. No calibrated expected return or learning is invented. This is an explicit allocation scenario, not native integer-share request-replay parity (native replay also has sector limits and a different priority rule). Positions are fractional, actual filled average entry/stop state feeds the next decision, and missing held data aborts. Nineteen entry evaluations lacked native features and abstained. GA7 begins deciding at the first 2009 close, so its earliest fill is January 5; no pre-model December 2008 niche was invented.

Common execution uses close decisions/next-open fills, **5bps commission plus 5bps adverse slippage on every buy and sell**, T+1 sale settlement throughout, zero cash yield, price returns with no separate dividend credit, no borrowing, and no terminal liquidation. These are all modeled costs; spread/impact beyond the 5bps slippage allowance, taxes and historical settlement reconstruction are unavailable. The common fixed control queues a one-session retry of cash-clipped monthly buys after sale proceeds settle, retaining the original signal's target dollars. GA7 cash-clipped requests are not retried automatically. The original control separately retains its exact adjusted-price, 10bps self-financing commission and same-open cash reuse convention. Its adjusted basis may embed dividend adjustments; it is a reference, while the common-accounting pair shares raw price-return conventions.

## Executed net results

Initial capital $100,000; CAGR annualizes by 252/2,516; MDD uses daily close marks, and the exact original additionally includes next-opening endpoints. No 2019 terminal prices are used. Final NAV includes open positions at the final close.

|---|---:|---:|---:|---:|---|---:|
| Exact existing fixed-month RSI+setup | 33.30% | 32.42% | 1.027 | 76.67% monthly target | 321 stock-months; 312 buy / 301 sell legs | $1,763,123 |
| Fixed-month screen, common execution | 32.62% | 29.45% | 1.108 | 74.16% mean daily | 302 entries; 292 completed; 10 open | $1,675,451 |
| Screened existing GA7 bank + allocation | 1.95% | 3.09% | 0.629 | 3.75% mean daily | 438 entries; 438 completed; 0 open | $121,219 |
| GA6 / combined GA6+GA7 | unavailable | unavailable | unavailable | unavailable | PIT niche routing blocked | unavailable |

The common fixed control held positions on 1,907 sessions and executed 646 fills. GA7 held positions on 1,516 sessions and executed 2,453 fills: **438 entry buys, 51 adds, 1,526 reductions, 438 exits**. Fractional reductions can create small residual positions; active-session counts therefore are not capital exposure. Counts of decisions differ from fills because of screen rejection, caps, cash clipping and minimum-notional suppression. Full counts appear in `metrics.json`, decisions and orders.

These are cumulative realized dollar costs on growing equity, not percentages of initial capital. GA7's low MDD accompanies very low capital deployment; this replay gives no evidence that the small arbitrary bank improves on fixed-month RSI+setup. The comparison mixes selection, daily management and allocation and does not isolate their effects. It does not establish that every existing GA7 chromosome would fail. No unscreened or exposure-matched GA7 run was added to this tight scope.

## Validation and artifacts

`exact_reference_monthly.csv` independently recomputes every original monthly NAV and asserts agreement with the saved original path at 1e-12 relative tolerance. `verify.py` independently rebuilds shares, settled/unsettled cash and daily NAV from exported fills and source closes; verifies fill timing, screen membership for GA7 buys, both cost formulas, and exported CAGR/MDD. Both common paths reconcile within $3e-9. Validation passed; see `verification.json` and `validation.log`.

`replay.py`, `run.sh`, `PLAN.md`, `bank.json`, `audit.json` (source hashes, library counts, niche support), `metrics.json`, and per-arm daily/fill/order/decision CSVs make the result reviewable. Source adapters are imported read-only with bytecode writes disabled. Completing a faithful combined replay requires an authentic historical GA6 niche classifier/mapping and training-lineage eligibility; changing those genes or fitting a new bank was outside this request.
